# Kiroween night is the default theme

For the Kiroween 2026 submission (category Resurrection), CARRY ships a dark "Kiroween night" theme as the default and keeps the original light theme as a choice in Settings. The night theme is a lantern-in-the-dark look, not a horror costume: no ghosts, gore or warning-tape, so the product still reads as a community utility. Colours are role tokens (canvas, surface, text, accent, brand, primary, signal, danger, acknowledged) defined as CSS variables, so both themes share every component and must each pass WCAG AA. QR codes always render dark-on-white in both themes, because scanning needs maximum contrast.

## Considered Options

- **Costume Contest horror UI**: scores on spookiness but weakens Potential Impact and contradicts the brand's "friendly utility" rule.
- **Light theme only**: no Halloween presence at all in a Halloween-themed hackathon.
