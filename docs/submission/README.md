| [`social-post.md`](social-post.md) | Social post drafts starting with #KiroweenHackathon26 |

## Only the owner can do these

1. **Rehearse on three real phones.** Do DEMO_PLAN.md five times, in Airplane Mode, A → B → C and back. Write down the numbers from Settings → Rehearsal measurements. If scans are slow, lower Settings → QR frame size.
2. **Record the video** using `video-script.md`. Keep it under 3:00, upload it publicly to YouTube, and check that it plays in a private window.
3. **Make the GitHub repository public** (https://github.com/FlamionZ/Carry). Check that the About panel shows the MIT licence, and add the live URL as the website.
4. **Fill in the Devpost form** from `devpost.md`: category Resurrection, repository URL, live URL and video URL. Add 3–5 screenshots: the welcome screen, the QR frames, the relay journey, Acknowledged, and the Ledger.
5. **Publish the blog post** from `blog-post.md`, then add its link where Devpost asks for it.
6. **Publish the social post** from `social-post.md`, then add its link where Devpost asks for it.
7. **Answer the eligibility questions honestly.** Student status decides whether "Best Student Project" applies. Any entry in Kiroween 2025 does not matter for this project, but answer what the form asks.
8. Optional: install Kiro CLI. If you use it before the deadline, add what you did to `KIRO.md`. If not, `KIRO.md` already says it was not used.
